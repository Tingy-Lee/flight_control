# 无人机竞赛项目上下文

更新时间：2026-04-16

## 项目定位

参加“全国大学生嵌入式芯片与系统设计竞赛 2026 / 芯片应用赛道 / 沁恒赛题”的选题一：无人机应用。

作品方向是“基于低空巡检场景下的自研发四轴无人机”，推荐命名为：

“基于 CH32H417/CH32V203 的四旋翼智能巡航无人机系统”。

核心目标是在 2026-06-08 前完成一台可遥控稳定飞行、定高悬停、定点/航点飞行的四旋翼无人机，并形成可答辩、可演示、可复现实验记录的工程项目。

## 团队与目标

项目发起人：

- 李天屹：东南大学吴健雄学院，本科大一，未来机器人专业。
- 苏皆睦：东南大学吴健雄学院，本科大一，电子信息专业。
- 刘家璇：东南大学吴健雄学院，本科大一，电子信息专业。

项目目的：

- 在无人机制作与功能实现过程中学习嵌入式系统、飞控、电调、电机控制与工程调试能力。
- 在嵌入式芯片与系统设计大赛应用赛道中获奖。

预算预期约 5000 元。

## 赛题硬约束

来自《沁恒赛道.pdf》的选题一要求：

- ESC 必须使用 CH32V203 开发。
- 飞控必须使用 CH32H41x 平台开发。赛题正文写 CH32H415，但平台页列出 CH32H417/5，当前项目按 CH32H417 执行。
- 无人机需要支持定高飞行。
- 无人机需要支持航点规划。
- 作品应体现嵌入式控制系统设计能力、无人机动力系统应用能力、飞控算法开发与实现能力。

加分方向：

- 高速电机性能调优与智能控制策略。
- 飞控与动力系统协同设计，提高续航或负载能力。
- 自主飞行任务、避障或智能巡航。
- 边缘 AI 环境感知，但不应成为主线风险点。

## 推荐总体路线

主线采用“稳妥落地 + 少量低风险创新”的方案：

- 四旋翼 X 架构。
- CH32H417 做飞控主控。
- 4 个 CH32V203 单路 ESC，自研电调控制板。
- 飞控实现稳定飞行、定高、GPS 航点任务、安全状态机、日志。
- 电调采用六步换相，不以 FOC 作为主路线。
- 主演示场景放在室外低速 GPS 航点任务：起飞 -> 定高悬停 -> 飞 3 到 4 个航点 -> 返回或降落。
- 创新点优先选“飞控-动力协同优化”“黑匣子日志与任务可视化回放”“智能任务状态机”。

绝对优先级：

1. 稳定飞行。
2. 定高成功率。
3. 航点任务闭环演示。

如果最终只能保住 3 个亮点：

1. CH32H417 飞控完整自研。
2. CH32V203 四路 ESC 自研并实飞。
3. 稳定完成定高 + 航点任务演示。

## 硬件方案

飞控主控：CH32H417

- 负责传感器采集、姿态/高度估计、控制律计算、航点任务、安全状态机、参数与日志。
- 使用 MounRiver Studio 和沁恒 EVT 作为主要开发基础。

ESC 主控：CH32V203

- 负责 PWM 输入解码、六步换相、启动逻辑、过流/欠压/堵转保护、转速估计和可选遥测。
- MVP 采用 PWM 输入，1000 到 2000 us 油门命令。
- DShot 与遥测作为后续增强项。

传感器与外设建议：

- IMU：ICM-42688-P 或 BMI270，优先 SPI。
- 气压计：BMP388 或 SPL06-001。
- GPS：u-blox M8N / M10 系列模块。
- 磁力计：建议加，但做成可关闭依赖，优先放在 GPS 模块附近并远离大电流。
- 定高：MVP 采用气压计 + 下视 ToF；光流作为备选增强，不卡主线。
- RC 接收机：UART/SBUS 等成熟方案。
- 电源检测：电池电压/电流 ADC。
- 调试：WCH-Link，飞控至少 2 路串口调试口，ESC 预留独立调试接口。

动力系统建议：

- 450/430 级四旋翼机架。
- 2212/2216 级电机。
- 10 到 11 寸桨。
- 3S 5200 mAh 或 4S 4200 mAh LiPo。
- 起飞重量控制在中等范围，不追求重载。

自研/外购边界：

- 飞控主控板：建议自研。
- ESC 控制板：建议自研。
- ESC 功率级：可自研，也可参考成熟拓扑做简化。
- 机架、电机、桨、电池、遥控器、传感器模块：直接买成熟件。
- 地面站：简易自制即可。

## 飞控软件架构

推荐分层：

- 应用层：任务管理、手动/定高/航点/降落、安全状态机、参数、日志。
- 控制层：位置控制、高度控制、姿态控制、角速度控制。
- 估计层：IMU 预处理、姿态解算、高度估计、GPS 航向/位置简化融合。
- 驱动层：IMU、Baro、GPS、Mag、ToF、RC、PWM 输出、ADC/电源检测。

必做驱动：

- IMU
- 气压计
- GPS
- RC 接收机
- 电池电压/电流
- 4 路 ESC 输出

选做驱动：

- 磁力计
- ToF
- 光流

姿态解算：

- 推荐 Mahony AHRS。
- 备选 Madgwick。
- 初期不做完整 EKF。

控制器：

- 角速度环：PID，约 1 kHz。
- 姿态环：P/PI，约 200 到 500 Hz。
- 高度环：高度 P 外环 + 垂速 PI 内环。
- 水平位置环：位置 P 外环 + 速度 PI 内环。

状态机至少包含：

- LOCKED
- STANDBY
- TAKEOFF
- ALT_HOLD
- MISSION
- RTL / LAND
- FAILSAFE

日志至少记录：

- gyro/acc
- roll/pitch/yaw
- target attitude / actual attitude
- target altitude / actual altitude
- throttle / motor mix
- GPS 坐标 / 速度
- mission state
- error flags

## ESC 实现路线

采用六步换相，不把 FOC 作为两个月内主路线。

原因：

- 无人机 ESC 最重要的是启动成功率、实时性、保护和响应。
- 六步换相实现和调试周期更短，四路复制风险更低。
- CH32V203 足够做竞赛级六步无人机 ESC，前提是不追求复杂 FOC 和花哨遥测。

ESC 开发阶段：

1. 台架阶段：单 ESC + 单电机，不上桨。
2. 半实物阶段：4 路并联测输入响应。
3. 整机阶段：先无桨，再小桨，再正常桨。

答辩需要展示：

- 原理图与 PCB。
- 六步换相状态图。
- 启动过程。
- 过流/堵转/欠压保护。
- 单电机测试波形。
- 四路一致性测试。
- 实飞视频与日志。

## 定高与航点

最小可行定高：

- 气压计做中高空相对高度。
- 下视 ToF 做低空精修。
- 垂向加速度仅辅助，不做复杂融合。
- 高度误差转目标垂直速度，垂直速度误差转油门修正，并加入倾角油门补偿。

最小可行航点：

- 室外 GPS。
- 预设 3 到 5 点。
- 限速低飞。
- 航点半径适当放大。
- 到点判定宽容。

演示原则：

- 室外主演示：GPS + 气压计 + ToF。
- 室内备演示：手动稳定 + 定高 + 简单矩形轨迹脚本。
- 保留人工接管开关。
- 所有状态机都能回退到 ALT_HOLD / MANUAL。

## 排期

计划书给出的关键时间线：

- 4/14-4/15：冻结总体方案，确定机架/传感器/动力采购，明确飞控板与 ESC 板原理图框架，完成系统框图、BOM、接口表、软件仓库与采购。
- 4/16-4/23：飞控基础驱动框架、ESC 单路底层驱动、PCB 第一版；完成 IMU/气压计/GPS 驱动、PWM 输出、RC 输入、ESC 六步换相定时器与 ADC 框架。
- 4/24-5/4：单 ESC 跑电机，飞控姿态解算跑起来，PCB 到板焊接开始。
- 5/5-5/10：飞控板初测、单路 ESC 稳定、整机静态联调；周末前飞控稳定读 IMU/Baro，输出 4 路命令，至少 1 路 ESC 稳定驱动电机，姿态环闭环可测。
- 5/11-5/17：首次离地，手动稳定模式，初步定高。
- 5/17-5/25：部分成员有事，补之前细节，为后续准备。
- 5/18-5/28：GPS 与任务系统上线，低速小范围航点测试，黑匣子日志完成；此后停止新增大功能。
- 5/29-6/6：提高成功率，修漏洞，增加一个低风险创新点，录制演示视频素材。
- 6/7-6/8：只做稳定性、演示和答辩，不改架构，完成视频、海报、PPT、代码仓库整理。

## 风险与降级

最高风险：

- ESC 启动不稳定，导致整机迟迟飞不起来。
- 姿态震荡或 IMU 振动导致飞行不稳。
- 定高漂移/抖动影响演示观感。
- GPS 漂移或现场环境不理想。
- 磁力计受电源与 ESC 干扰。
- PCB 一版失败。

必须准备的备份演示：

- 备份 1：手动稳定 + 定高。
- 备份 2：自动起飞 + 悬停 + 降落。
- 备份 3：短距离 2 点航线，而不是复杂多点任务。

明确可砍功能：

- 复杂 AI。
- 避障。
- 光流。
- 室内自主导航。
- DShot / 双向遥测。
- FOC。

## 默认工作原则

后续开发时，默认采用以下策略：

- 先打通最小闭环，再加功能。
- 优先飞起来、飞稳、可复现。
- 使用 PX4 / ArduPilot / INAV / AM32 / BLHeli_S 的架构思想和工程经验，但不完整移植。
- 代码和材料都要服务于“芯片使用符合题意、自研程度可证明、演示稳定、日志证据充分”。
- 第 6 周后不再扩大功能面，只做稳定性、演示流程、答辩材料和日志证据。
